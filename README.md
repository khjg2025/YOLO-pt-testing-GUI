# YOLO26 图片检测 GUI 工具

基于 PyQt5 和 Ultralytics YOLO 的图片检测可视化工具，支持单模型/双模型对比检测、标签绘制、差异排序等功能。

## 功能特性

### 基础功能
- **模型加载**：支持加载 `.pt` 格式的 YOLO 模型文件
- **目录选择**：选择待检测的图片目录和标签目录
- **批量检测**：对目录内所有图片进行批量检测
- **单张检测**：对当前显示的图片进行单次检测
- **图片浏览**：上一张/下一张切换图片（支持键盘方向键）
- **结果可视化**：在图片上绘制检测框和类别标签

### 双模型对比
- **单模型+标签模式**：左侧显示模型检测结果，右侧显示标签框
- **双模型对比模式**：左侧显示模型1结果，右侧显示模型2结果
- 可通过下拉菜单切换显示模式

### 标签支持
- 支持 YOLO 格式的标签文件（`.txt`）
- 标签文件与图片文件同名
- 自动根据图片文件名匹配对应标签

### 差异排序
- 计算模型检测结果与标签的差异分数
- 差异分数 = 未匹配的标签数×2 + 未匹配的检测结果数
- 点击"差异排序"按钮后，按差异从大到小排序
- 使用上一张/下一张优先查看差异大的图片

### 结果导出
- 支持导出检测结果为 JSON 格式
- 支持导出检测结果为 CSV 格式

### 历史记录
- 自动记录每次检测的时间、耗时、目标数、置信度
- 可查看历史检测详情

### 系统监控
- 实时显示 GPU 显存使用情况
- 实时显示 CPU 使用率
- 实时显示内存占用

### 参数持久化
- 退出时自动保存模型路径、检测目录、标签目录等参数
- 下次启动时自动恢复上次的设置

## 使用说明

### 1. 加载模型
1. 点击"选择模型文件"按钮，选择 `.pt` 模型文件
2. 可选：加载第二个模型用于对比

### 2. 选择目录
1. 点击"选择目录"按钮，选择待检测的图片目录
2. 点击"选择标签目录"按钮，选择标签文件目录（可选）

### 3. 调整参数
- **置信度阈值**：调整检测的置信度（1%~100%）
- **最大边长**：调整图片输入尺寸（320~1920px）

### 4. 执行检测
- **批量检测**：对目录内所有图片进行检测
- **单张检测**：对当前图片进行检测

### 5. 查看结果
- 左侧窗口：显示模型检测结果（带检测框）
- 右侧窗口：显示标签框或第二个模型结果
- 结果列表：显示检测详情和差异分数

### 6. 浏览图片
- 点击"上一张"/"下一张"按钮
- 或使用键盘方向键 `←` / `→`

### 7. 差异排序
1. 点击"差异排序"按钮
2. 程序会计算每张图片的差异分数并按降序排列
3. 使用上一张/下一张浏览差异大的图片

## 标签文件格式

标签文件使用 YOLO 格式，每行一个目标：

```
<class_id> <cx> <cy> <width> <height>
```

- `class_id`：类别 ID（整数）
- `cx, cy`：边界框中心点的归一化坐标（0~1）
- `width, height`：边界框宽高的归一化值（0~1）

示例：
```
0 0.5 0.5 0.2 0.3
1 0.3 0.4 0.1 0.2
```

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `←` / `→` | 上一张 / 下一张 |
| `Ctrl+S` | 单张检测 |
| `Ctrl+B` | 批量检测 |
| `Ctrl+O` | 打开目录 |
| `Ctrl+Q` | 退出程序 |

## 注意事项

1. 确保已安装 `ultralytics` 库：`pip install ultralytics`
2. 标签文件需与图片文件同名（扩展名不同）
3. 双模型对比模式需要先加载第二个模型
4. 程序会自动保存设置到 `last_settings.json`
